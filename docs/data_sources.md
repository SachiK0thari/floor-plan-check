## CubiCasa5K notes

- **Licence.** The two official sources disagree. The Zenodo record that hosts the files
  ([10.5281/zenodo.2613548](https://zenodo.org/records/2613548), version 1.0, 2019-03-28) says
  CC BY-NC-SA 4.0. The LICENSE file in the [CubiCasa5k GitHub repository](https://github.com/CubiCasa/CubiCasa5k)
  says CC BY-NC 4.0. The project follows the stricter one, CC BY-NC-SA 4.0: no commercial use;
  credit Kalervo et al. (2019) and link the record wherever results or images are shown; anything
  derived from the data that is published (masks, images of CubiCasa plans, and, to be safe, the
  trained weights) is released under CC BY-NC-SA 4.0. The CubiCasa code is also non-commercial and
  is not copied; `training/cubicasa_prep.py` is an independent parser.
- **Copy used.** The official archive is `cubicasa5k.zip`, 5,469,495,706 bytes, md5
  `0ce0b203d1e3c125b51087b219bd23b9`. Training reads the Kaggle copy `qmarva/cubicasa5k` instead,
  inside the author's Kaggle account. It was checked against the official layout on 2026-11-24:
  4,200 train, 400 validation and 400 test plans in the split files and 5,000 `model.svg` files.
  The Kaggle page labels it CC BY-NC-SA 3.0 IGO, which is the uploader's error; the Zenodo licence
  applies.
- **Format facts the parser relies on.** SVG coordinates are pixels of `F1_scaled.png`. One image
  can hold several drawings, one per `Floorplan` group (some hidden with `display: none`), and all
  of them are drawn onto that image. Wall, door, window, space and railing groups hold their
  polygon directly; fixed furniture holds a local polygon in a `BoundaryPolygon` group, placed by
  the group transforms.
- **Derived files on Kaggle.** The masks archive is the private output of the prep kernel. One
  training checkpoint is stored as the private dataset `sachikothari/plancheck-seg-checkpoint`
  (CC BY-NC-SA 4.0, created 2026-11-24 to resume a stopped run; it can be deleted once the run has
  finished).
- **No dataset files in the repository or in tests.** Tests use hand-written SVGs in the same
  layout.
